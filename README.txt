Blue Ventures wireframe prototype - standalone version

Open index.html in any browser. Double-clicking works; no server, no install, nothing to run.
Every page links to every other page, and the Prototype button (bottom right) opens the core
pages, the user flows with walkthroughs, and the change log.

This folder is generated. To change anything, edit src/config.ts in the main project and run
"npm run standalone" again.
